SQL, Lesson 2: explainer

Grouping: GROUP BY

Sometimes you don't need the rows themselves, but a number about them: how many sheep, how much they weigh in total, which pasture has the most. Aggregate functions turn many rows into one number, and GROUP BY does it for each group separately.

4GROUP BY: one result per group

When you need a number for each pasture instead of the whole flock, GROUP BY works in three steps:

  1. It puts rows with the same value into one group (one pen).
  2. It runs the aggregate function for each group separately.
  3. It returns one row per group.

5HAVING: filtering groups

6The order of the parts

You always write them in this order:

SELECT pasture, COUNT(*)what to show
FROM sheepwhich table
WHERE colour = 'white'filter rows
GROUP BY pasturemake groups
HAVING COUNT(*) >= 2filter groups
ORDER BY COUNT(*) DESC;sort
🔁

SQL carries them out in a different order, though: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY. That's why COUNT can't go in WHERE: there are no groups yet.

7Common mistakes

✗ Wrong
SELECT pasture, COUNT(*)
FROM sheep;
✓ Right
SELECT pasture, COUNT(*)
FROM sheep
GROUP BY pasture;

Without GROUP BY the whole table is one heap: you get a single row with 12 and a pasture name picked more or less at random.

✗ Wrong
SELECT pasture, COUNT(*)
FROM sheep
WHERE COUNT(*) > 3
GROUP BY pasture;
✓ Right
SELECT pasture, COUNT(*)
FROM sheep
GROUP BY pasture
HAVING COUNT(*) > 3;

WHERE runs before grouping, when there's nothing to count yet: you get a misuse of aggregate error.

✗ Wrong
SELECT name, COUNT(*)
FROM sheep
GROUP BY pasture;
✓ Right
SELECT pasture, COUNT(*)
FROM sheep
GROUP BY pasture;

A pen holds many sheep, yet only one name appears. SQLite gives no error, but the result is misleading.

8Check yourself

How many rows does this query return?
SELECT pasture, COUNT(*)
FROM sheep
GROUP BY pasture;

One row for each different pasture: 3.

Which one filters groups?

HAVING runs after grouping, so it may contain COUNT or SUM.

What is the average weight of the Stork Pond sheep?
SELECT AVG(weight_kg)
FROM sheep
WHERE pasture = 'Stork Pond';

(66 + 45 + 42) / 3 = 51. 153 would be the total (SUM).

Which order is right?

WHERE comes before grouping, HAVING after it.
