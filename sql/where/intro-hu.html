Szűrés: WHERE

Egy tábla gyakran több száz sorból áll, de neked csak néhány kell belőle. A WHERE olyan, mint egy szita: minden sort megvizsgál, és csak azokat engedi át, amelyekre igaz a feltétel.

1A példatábla

Ezen a lapon minden példa ugyanazt a kis táblát használja: egy múzeum látogatóit egy délutánon.

latogatok
💡

Egy sor egy látogató, egy oszlop egy tulajdonság (pl. magassag). A SELECT az oszlopokat választja ki, a WHERE a sorokat.

2A lekérdezés részei

Minden lekérdezés ugyanazokból a részekből áll, és ezek mindig ebben a sorrendben követik egymást:

SELECT nev, magassagmely oszlopokat mutassa (a * az összeset jelenti)
FROM latogatokmelyik táblából olvasson
WHERE magassag > 180mely sorok maradjanak – ez a szűrés
ORDER BY magassag DESC;hogyan legyenek sorba rendezve (nem kötelező; DESC = csökkenő)
Próbáld ki – át is írhatodCtrl + Enter

Írd át a 180-at 170-re, és futtasd újra. Hány sor lett?

3Összehasonlítás

A feltétel általában egy oszlopot hasonlít össze egy értékkel. Ezeket a jeleket használhatod:

jeljelentésepélda
=egyenlőkabat = 'piros'
<>nem egyenlőkabat <> 'piros'
>nagyobbkor > 30
<kisebbkor < 18
>=nagyobb vagy egyenlőmagassag >= 181
<=kisebb vagy egyenlőmagassag <= 165

Szöveg vagy szám?

  • A szöveg mindig egyszeres idézőjelbe kerül: 'piros'. A kis- és nagybetű számít: 'Piros' nem ugyanaz.
  • A szám idézőjel nélkül áll: 180.
  • Az időpontok itt szövegként vannak tárolva ('16:40'). Mivel mindig ÓÓ:PP alakúak, a > és a < rájuk is jól működik.

5Hiányzó érték: NULL

B. Rozália sorában a tavozas mező üres: NULL. Ez azt jelenti, hogy nincs adat – talán még bent van a múzeumban.

A NULL nem egyenlő semmivel, még önmagával sem, ezért = NULL helyett ezt kell írni:

feltételjelentése
IS NULLnincs érték
IS NOT NULLvan érték

6Minta szerint: LIKE

Ha nem a teljes szöveget ismered, csak egy részét, a LIKE mintát keres. A mintában:

jeljelentésepélda
%bármennyi (akár nulla) tetszőleges karakter'M%' = M-mel kezdődik
_pontosan egy tetszőleges karakter'_. %' = egy betű, pont, szóköz az elején
Próbáld ki – át is írhatodCtrl + Enter

Próbáld ki: '%a' (a-ra végződik) vagy '%Anna%' (valahol benne van).

7Gyakori hibák

✗ Hibás
SELECT nev FROM latogatok
WHERE kabat = piros;
✓ Helyes
SELECT nev FROM latogatok
WHERE kabat = 'piros';

Idézőjel nélkül az SQL a piros szót oszlopnévnek hiszi, és ezt a hibát kapod: no such column: piros.

✗ Hibás
SELECT nev FROM latogatok
WHERE tavozas = NULL;
✓ Helyes
SELECT nev FROM latogatok
WHERE tavozas IS NULL;

Az = NULL soha nem igaz, ezért 0 sort kapsz, és hibaüzenet sem figyelmeztet.

✗ Hibás
SELECT nev FROM latogatok
WHERE magassag > 180
  AND kabat = 'piros'
   OR kabat = 'narancs';
✓ Helyes
SELECT nev FROM latogatok
WHERE magassag > 180
  AND (kabat = 'piros'
    OR kabat = 'narancs');

Zárójel nélkül az OR utáni rész külön áll: minden narancs kabátos bekerül, a magasságától függetlenül (L. Zorka 158 cm, mégis ott van).

✗ Hibás
SELECT nev
WHERE kor < 18
FROM latogatok;
✓ Helyes
SELECT nev
FROM latogatok
WHERE kor < 18;

A részek sorrendje kötött: SELECT → FROM → WHERE → ORDER BY.

8Ellenőrizd magad

Mit csinál a WHERE?

Az oszlopokat a SELECT választja, a sorokat a WHERE.

Melyik feltétel helyes, ha a kék kabátosokat keresed?

A szöveges érték idézőjelbe kerül, az oszlop neve nem.

Hány sort ad ez a lekérdezés a példatáblán?
SELECT nev FROM latogatok
WHERE kor < 18 OR magassag > 180;

Az OR-nál elég az egyik feltétel: 2 fiatal és 4 magas látogató, de S. Bálint Máté mindkettő, így csak egyszer számít: 5. Ellenőrizd a fenti dobozok egyikében!

Hogyan találod meg azt, akinek nincs távozási ideje?

A hiányzó értéket csak IS NULL-lal lehet megtalálni.
