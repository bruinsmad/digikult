SQL, Lesson 1: explainer

Filtering: WHERE

A table often has hundreds of rows, but you only need a few of them. WHERE works like a sieve: it checks every row and lets through only the ones for which the condition is true.

1The example table

Every example on this page uses the same small table: the visitors of a museum on one afternoon.

visitors
💡

One row is one visitor, one column is one property (like height_cm). SELECT picks columns; WHERE picks rows.

2The parts of a query

Every query is made of the same parts, and they always come in this order:

SELECT name, height_cmwhich columns to show (* means all of them)
FROM visitorswhich table to read
WHERE height_cm > 180which rows to keep: this is the filter
ORDER BY height_cm DESC;how to sort the result (optional; DESC = largest first)

3Comparing

A condition usually compares a column with a value. You can use these signs:

signmeaningexample
=equalcoat = 'red'
<>not equalcoat <> 'red'
>greater thanage > 30
<less thanage < 18
>=greater or equalheight_cm >= 181
<=less or equalheight_cm <= 165

Text or number?

  • Text always goes in single quotes: 'red'. Capitals matter: 'Red' is different.
  • Numbers have no quotes: 180.
  • Times are stored as text here ('16:40'). Because they always have the HH:MM shape, > and < work on them too.

5Missing values: NULL

In B. Rozália's row the exit_time field is empty: NULL. It means no data: maybe she is still inside the museum.

NULL isn't equal to anything, not even to itself, so instead of = NULL you write:

conditionmeaning
IS NULLthere is no value
IS NOT NULLthere is a value

signmeaningexample

7Common mistakes

✗ Wrong
SELECT name FROM visitors
WHERE coat = red;
✓ Right
SELECT name FROM visitors
WHERE coat = 'red';

Without quotes SQL thinks red is a column name, and you get the error no such column: red.

✗ Wrong
SELECT name FROM visitors
WHERE exit_time = NULL;
✓ Right
SELECT name FROM visitors
WHERE exit_time IS NULL;

= NULL is never true, so you get 0 rows, and no error message warns you.

✗ Wrong
SELECT name FROM visitors
WHERE height_cm > 180
  AND coat = 'red'
   OR coat = 'orange';
✓ Right
SELECT name FROM visitors
WHERE height_cm > 180
  AND (coat = 'red'
    OR coat = 'orange');

Without brackets the part after OR stands on its own: everyone in an orange coat gets in, whatever their height (L. Zorka is 158 cm, yet she's there).

✗ Wrong
SELECT name
WHERE age < 18
FROM visitors;
✓ Right
SELECT name
FROM visitors
WHERE age < 18;

The order of the parts is fixed: SELECT → FROM → WHERE → ORDER BY.

8Check yourself

What does WHERE do?

SELECT picks the columns, WHERE picks the rows.

Which condition is right if you want the people in blue coats?

The text value goes in quotes; the column name doesn't.

How many rows does this query return on the example table?
SELECT name FROM visitors
WHERE age < 18 OR height_cm > 180;

With OR one condition is enough: 2 young and 4 tall visitors, but S. Bálint Máté is both, so he counts once: 5. Check it in one of the boxes above!

How do you find the visitor with no exit time?

A missing value can only be found with IS NULL.
