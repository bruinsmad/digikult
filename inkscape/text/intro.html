Inkscape, Lesson 2: explainer

Text and text boxes

On a poster, text is drawing too: it can be bold and outlined, run round a circle or along a wave, fill a shape, and even become a shape. This lesson shows which method is for what.

1Click or drag

With the Text tool (T) you can start typing in two ways:

  • Click: one line of text. It goes on until you press Enter – it never wraps by itself.
  • Drag: a text box (a frame). Lines wrap at the frame's edge on their own, and you can resize the frame later.
Try it: a line or a frame

2Font, size, fill, outline

Font and size are set in the tool controls bar above the canvas while the Text tool is active. Text colour is a fill, just like a shape's, and text can have an outline too: Object ▸ Fill and Stroke….

Try it: size, spacing, outline
💡

You can colour a single letter: select it with the Text tool, as in a word processor, and click a colour in the palette.

3Text on a path

Draw a circle or a line, type the text, select both, and Text ▸ Put on Path. The text runs along the line, and if you reshape the line later, the text follows.

Try it: circle or wave, start point, direction
If the text runs upside down or on the inside, don't rotate the text: select the path and Path ▸ Reverse.

4Text poured into a shape

Text ▸ Flow into Frame uses a shape – a circle, a star, anything – as the frame: the lines reach right to its edge. Select the text and the shape, then the menu item. The shape stays where it is; if it shouldn't show, remove its fill.

What it looks like: text flowed into a circle

5Text into a shape

Path ▸ Object to Path turns text into letter-shaped paths. After that the letters behave like any other shape: cut them out of another one (Path ▸ Difference) or pull spikes out of them with the Node tool.

Try it: text or path
💡

Before converting, make a copy (Edit ▸ Duplicate) and set it aside. If you spot a typo later, you can start again from the copy.

6Common mistakes

✗ What happened

The text runs off the page and doesn't wrap.

✓ How to fix it

Drag a frame with the Text tool instead of clicking.

A click gives you one line, and a line doesn't wrap.

✗ What happened

The text on the circle runs upside down, inside the circle.

✓ How to fix it

Select the circle, then Path ▸ Reverse.

The path's direction decides which side the text sits on.

✗ What happened

I spotted a typo after Object to Path.

✓ How to fix it

Edit ▸ Undo, fix it, and convert afterwards.

A path isn't text any more; it can't be retyped.

✗ What happened

Flow into Frame is greyed out.

✓ How to fix it

Exactly two things must be selected: the text and the shape.

7Check yourself

How do you get text that wraps onto new lines by itself?

In a text box made by dragging, lines wrap at the edge on their own.

The text on a circle runs inside it, upside down. What do you do?

Reverse the path's direction, and the text moves to the outside of the circle.

What does text become after Object to Path?

So fix the text first, and convert it afterwards.

You want letters cut out of a red rectangle (stencil letters). What's the right order?

Same as the craters: the text becomes a path first, and the top one cuts.
