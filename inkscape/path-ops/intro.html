Inkscape, Lesson 1: explainer

Path operations and nodes

In Inkscape you don't draw complicated shapes, you build them: two simple shapes and the Path menu give you a third – a cratered moon, a ring, a rocket body with a flat bottom. With the Node tool you can then pull any corner on its own.

1Shape or path

What you draw with the Rectangle, Ellipse or Star tool is a shape: it knows it is a rectangle (or ellipse, or star) and can only change as one – bigger, smaller, rounder corners.

After Path ▸ Object to Path the same thing is a path: a row of points, called nodes, joined by straight or curved segments. From then on you can move any node on its own.

💡

The result of a path operation is always a path. So a cut-out moon or a ring can still be reshaped with the Node tool afterwards.

2The four path operations

Select two overlapping shapes – click the first, Shift + click the second – and choose from the Path menu:

  • Union: the two become one, with a single outline.
  • Difference: the top one cuts a piece out of the bottom one.
  • Intersection: only the overlap is kept.
  • Exclusion: everything is kept except the overlap.
Try it: pick an operation

3Which one is on top? That decides it

For Difference it matters which shape is on top: the top one cuts, the bottom one stays. In the example above, untick “The square is on top” and look at Difference again.

If it came out the wrong way round: Edit ▸ Undo, select the shape that should do the cutting, Object ▸ Raise to Top, and try again.

Rule: Difference and Intersection need exactly two objects selected; Union takes any number. If the menu item is greyed out, check the status bar at the bottom: how many objects are selected?

To cut several pieces at once (say, five craters), first join them to each other (Path ▸ Union), then select the Moon and the joined craters for Difference.

4Nodes and handles

The Node tool (the second button in the toolbox, or N) shows a path's nodes. Drag one and only that corner moves; the others stay put. Between two nodes the segment can be straight or curved; on a curve a small arm, the handle, sticks out of the node, and you bend the line with it.

Try it: drag the handles, then the nodes

That's why the Node tool shows a square and a round handle on a plain rectangle instead of its corners. You only get separate, movable corners after turning it into a path.

5Common mistakes

✗ What happened

The Moon vanished instead of the craters.

✓ How to fix it

The craters must be on top: Object ▸ Raise to Top, then Difference.

The top shape always cuts; the bottom one stays.

✗ What happened

Difference is greyed out.

✓ How to fix it

Exactly two objects must be selected: the Moon and the joined craters.

It won't work with five separate craters – Union them first.

✗ What happened

The Node tool shows a square and a circle, not the corners.

✓ How to fix it

First Path ▸ Object to Path.

It's still a shape, not a path.

✗ What happened

I try to drag a node, but the whole shape moves.

✓ How to fix it

Pick the Node tool (N).

The Selector tool always moves the whole object.

6Check yourself

A small circle sits on top of a big circle, and both are selected. What does Difference give you?

The top (small) circle cuts a piece out of the bottom one, then disappears.

Which operation keeps only the part the two shapes share?

Intersection: only where both are – that's how the rocket body gets its flat bottom.

You want to cut five craters out of the Moon. What's the right order?

Difference needs exactly two objects, so join the craters first.

What does Object to Path do to a rectangle?

Afterwards the Node tool can pull any corner on its own – that's how a rectangle becomes a wing.
