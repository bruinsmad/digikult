Keyboard shortcuts, as in VS Code
ul>li*3 + Tab
Emmet: short codes become full HTML. Try p, img, table>tr*3>td*3, !
m10 + Tab (in CSS)
Emmet for CSS: m10 → margin: 10px;, c → color, bgc → background-color. Colours get a small swatch.
